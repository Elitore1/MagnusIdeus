⚡ Esclarificador

Transpilador experimental de C++ a Python, JavaScript y Rust

Python JavaScript Rust C++

🚀 ¿Qué hace?

Convierte código C++ (simple) en código ejecutable en tres lenguajes diferentes mediante un sistema de mapeos configurable.

📖

Interpreta C++

Genera un AST desde tu código fuente

🔧

Mapea Abstracciones

Configurable mediante mappings.json

🚀

Genera Código

Python, JavaScript y Rust

✅

Pipeline Completo

Un solo comando: ./run.sh

📖 Ejemplo de Código

C++ (src/idea.cpp):

// Abstracción: Tanger (Problema) class Tanger {
  public:
    std::string problema = "renderizado_3d";
    void diagnosticar() { std::cout << "Problema identificado\n"; }
};

Python (output/generated/idea.py):

class Problem:
  def __init__(self):
    self.problema = ""

  def diagnosticar(self):
    print("🔍 Diagnosticando Tanger...")
    return True

⚙️ Cómo Usar

# 1. Clonar el repositorio
git clone https://github.com/tu-usuario/esclarificador.git
cd esclarificador

# 2. Ejecutar el pipeline completo
./run.sh

# 3. O usar comandos individuales
python3 bridge/main.py generate --lang python
python3 bridge/main.py generate --lang js
python3 bridge/main.py generate --lang rust
